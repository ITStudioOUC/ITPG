# ITStudio Project Garden

爱特工作室自主开发的项目组织招募平台。旨在帮助工作室成员更好地分享项目想法、组织项目开发、贡献开源项目。

平台设计围绕项目想法分享的正式化、公开化和有组织化展开。用户可将成型的项目想法发布到平台，经过审核后向其他用户展示与推荐；用户也可以认领其他人的项目想法，与发布者取得联系继续开发，并持续在平台跟进项目进度。

## Feature

- 可配置的登录后端，通过 Github 及工作室统一认证可直接注册账号
- 多层次的用户权限，用户、管理员、超级管理员拥有不同层级权限
- 标准化的发布机制，项目需要填写人数、内容、开发周期、技术路线和需求等内容，并在审核后才可展出
- 全流程的跟进流程，项目开发后会自动抓取项目进展，以可视化的树状图展示，并添加代码分析功能
